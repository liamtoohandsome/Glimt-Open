# Contributing

Thanks for taking an interest in Glimt Open.

## Before opening a pull request

1. Keep changes focused and explain the user-facing or developer-facing problem.
2. Add or update unit tests for behavior changes.
3. Run: python -m unittest discover -s tests -v
4. Do not add binaries, recordings, API keys, credentials, private user data, or commercial Glimt source.
5. Keep the tool local-only unless a network feature is discussed and reviewed first.

## Issues

Please include your operating system, Python version, FFmpeg version, exact command, and a short sanitized error message. Do not attach private gameplay recordings unless you have permission to share them.
